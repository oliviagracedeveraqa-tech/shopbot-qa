# ShopBot QA

I'm testing an AI customer-service bot for RK Shop, a fictional fashion retail store in the Philippines. This project uses AI QA tools to check that the bot gives customers accurate, helpful, and safe answers.

## Roadmap

- **L1:** SKILL.md test generator
- **L2:** n8n bug triage
- **L3:** DeepEval tests
- **L4:** LangGraph routing
